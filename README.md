# Currency-Convertor-using-Python
A modern Python currency converter built with CustomTkinter. It supports 20+ currencies, currency swapping, conversion calculations, exchange-rate display, and comparison cards through a clean and interactive graphical interface.

### Features

* Supports 20+ currencies
* Simple and interactive GUI
* Currency selection through dropdown panel
* Currency swap functionality
* Displays conversion results and exchange rates
* Shows currency comparison cards
* Input validation for invalid values
* Light-themed modern interface

### Technologies Used

* Python
* CustomTkinter
* Tkinter GUI concepts
* Dictionaries and functions

### Purpose

This project demonstrates how Python can be used to create an interactive desktop application with a graphical user interface and currency conversion logic.
